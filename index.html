💡 Tips

  • Paste order on Character.AI's create form: Name → Tagline → Description → Greeting → Alternate greetings → Advanced creation → Definition → Visibility (Private).
  • Character.AI allows a main greeting + 4 alternate greetings. Alt greeting titles are only shown for you — Copy grabs just the text.
  • Character.AI name max is 20 characters.
  • The Definition goes under Advanced creation on Character.AI.
  • If an avatar is rejected, try a face-only crop.
  • A lorebook holds 128 entries max — start a second lorebook when it's full.
  • Your API key is stored only on this device.
